# Tetra VISION — browser game

Latest single-player browser build with tactical opponents, tutorials, collection, workshop and 27 adaptive Story rounds. Saves are stored on this device; use Save & sync export/import to transfer progress. No hosted multiplayer or account/cloud service is included.

431 original mythology artwork bindings; research/editorial limitations remain. Memoria, font and fflate license notices are included. Native app releases remain paused.
